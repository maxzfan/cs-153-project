## PDF generation checklist

1. In the Google Doc: **File → Download → PDF Document (.pdf)**
2. Save as `0studio-design-partner-loi.pdf` to your Desktop or `~/0studio/loi/`
3. Verify file size: target **under 200KB**. If larger, run through `https://www.ilovepdf.com/compress_pdf` (smaller PDFs trigger fewer spam filters)
4. Filename rules: do NOT name it `LOI_FINAL_v3.pdf` or anything with multiple underscores, "FINAL," version markers, or numbers — those are spam-filter triggers. Stick to `0studio-design-partner-loi.pdf`
5. Don't password-protect the PDF and don't lock it as read-only — that breaks Preview's signature tool on the recipient's end
6. Open the PDF in Preview yourself once → confirm the signature/name/title/firm fields are clearly visible blank lines that the recipient can sign on or type into

## What happens when a firm signs

- Architect opens the PDF in Preview/Adobe/iPhone Mail Markup
- Adds signature using the built-in signature tool
- Types name, title, firm into the blank fields
- Saves the modified PDF (Preview saves in place; Adobe Save As; iPhone Mail attaches the marked-up version automatically)
- Emails it back to `founders@0studio.xyz`

You'll see the signed PDF arrive as an email reply (or a new email with attachment). File it into `~/0studio/loi-signed/{firm-slug}.pdf` and update the spreadsheet `pdf_received_at` column.
